
# Lab 5: Static Code Analysis — Reflection

## 1. What is static code analysis?

Static code analysis examines source code without executing it to identify potential bugs, security vulnerabilities, and code-quality problems.

## 2. What are the differences between the tools?

- Pylint checks code quality, naming conventions, documentation, and potential programming errors.
- Bandit checks Python code for common security issues.
- Flake8 checks Python style and formatting violations.

## 3. What improvements were made?

Unsafe expression evaluation and shell execution were removed. SHA-256 and secure OTP generation were introduced. The code was also improved with better exception handling, function documentation, naming conventions, and file handling.

## 4. What did I learn?

I learned that static-analysis tools help identify issues early, improve readability, and make Python programs safer and easier to maintain.
